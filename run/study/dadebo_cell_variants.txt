# Dadebo CSTR cell study — the STRESS / ROBUSTNESS cell (stiff nonlinear delayed plant).
# NOT primary H2 evidence (the Mackey-Glass cells carry that, experimental_design.md §2.3,
# §6); the question here is whether the H1/H2 ordering SURVIVES a stiff, 4-D,
# state-dependent-gain B(x) plant with Arrhenius terms. Value-gradient backbone; value
# linear in the feature map Phi.
#
# Env: env=chemical_reaction_4D (Dadebo CSTR = Example 4 of Dadebo & Luus 1992;
# src/envs/chemical_process.py; delay tau=0.2, Q=I_4, R=0.1 I_2, step_size dt=0.01,
# resolution=4). The env reproduces the paper EXACTLY: same 4 ODEs, same x0, same cost
# I = int_0^tf (x^T Q x + u^T R u) dt with tf=2.0.
#
# REFERENCE OPTIMUM (ground truth): Dadebo & Luus, "Optimal Control of Time-Delay Systems
# by Dynamic Programming", Optimal Control Appl. & Methods 13, 29-41 (1992), Example 4,
# Table V: for tau=0.20 the optimal performance index is I* = 0.02386 (their iterative DP,
# P=40; Oh-Luus control-vector iteration gives 0.02372). Because eval/total_cost_agent is
# the dt-weighted integral cumsum(cost)*step_size (evaluate.py), the agents' raw J is the
# SAME quantity I and is DIRECTLY comparable to I*: the aggregator draws I* as a dashed
# ground-truth line on the chemical-reaction panel (KNOWN_OPTIMA in
# aggregate_representation_study.py) and the report states normalised sub-optimality
# rho = (J - I*)/I*. There is no closed-form FEEDBACK law (the paper gives an open-loop
# optimal trajectory via DP), so the aggregator still routes this env to the raw-J branch
# (ChemicalReactionEnv is a SUBCLASS of JAXDDEEnv, not JAXDDEEnv itself); I* is overlaid as
# a reference, not used to renormalise inside the aggregator. All variants share env, seed,
# window, horizon, and budget.
#
# CONDITIONING (experimental_design.md §6, pinned empirically 2026-06-11 on this machine):
#   The plant is OPEN-LOOP STABLE at x0=[0.15,-0.03,0.1,0.0] (zero control: max|x|~=0.45,
#   settles; per-step random control even at U[-5,5] stays bounded ~0.6). Divergence to NaN
#   occurs ONLY under SUSTAINED negative control of magnitude >~2 (the Arrhenius positive-
#   feedback channel: u<0 enlarges x2,x4 via the -u*(x+0.25) term, inflating
#   R = (x1+0.5) exp(25 x2/(x2+2))). The critic-only agent (critic std_init=0.01 so
#   dV/dx~=0 at init; smooth exploration sigma=0.1) does NOT enter that regime: a no-clip
#   smoke run (60 ep, 1 seed) left ALL of {markovian, raw deg1/2, signature depth2/4}
#   bounded and learning (25-40% cost reduction). Hence NO action clip is used here
#   (clip_action=null keeps the EXACT Doya control law u=1/2 R^-1 B(x)^T dV/dx, identical to
#   the MG/linear cells); the only safeguard is divergence_threshold + best-state restore.
#   See the comment block in src/envs/chemical_process.py for the documented constraint.
#
# Launch --common (matched information set across variants — same window/cadence/horizon/budget):
#   env=chemical_reaction_4D
#   agent.signature.window_size=23        # covers delay 0.2 at dt 0.01 (20 taps + margin);
#                                         # identical to the auto-computed window, set
#                                         # explicitly so every variant shares it.
#   agent.training.max_time=2             # controlled horizon = paper horizon tf=2.0
#   agent.training.clip_action=null       # NO clip: exact Doya law (see CONDITIONING above)
#   agent.training.divergence_threshold=50 # episode-abort safeguard for the stiff plant
#   agent.training.critic_lr=2e-2         # from the no-clip conditioning sweep (job 163009):
#                                         # lr=2e-2 reached the lowest cost; lr=1e-2 was worse
#                                         # and tau_polyak/integral_td gave no gain (the
#                                         # latter is not a valid value_gradient key).
#   eval.x0_test=[0.15,-0.03,0.1,0.0] eval.T_sim=2   # paper x0 and horizon tf=2.0
#   agent.training.n_episodes=1500        # converged budget: at 1500 ep the markovian reaches
#                                         # I=0.02696 (rho=+0.13 vs the DP optimum), vs I=0.0299
#                                         # at 800 ep; the higher budget also lets the higher-dim
#                                         # signature variants converge for a fair H2 comparison.
#
